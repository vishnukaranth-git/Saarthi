## Brand & Style

This design system establishes a high-trust, institutional-grade visual foundation tailored for merchant growth intelligence and financial autonomy. Balancing authoritative banking discipline with next-generation agentic utility, the aesthetic combines the meticulous typographic density of Linear with the pristine, reassuring surface quality of Stripe and Ramp.

### Personality & Emotional Response
- **Institutional Assurance:** Merchants entrust mission-critical liquidity, settlements, and customer intelligence to the system. Surfaces must project absolute reliability, precision, and architectural balance.
- **Quiet Intelligence:** Intelligence is communicated through structured analytical density, pristine hierarchy, and calm feedback loops rather than flashy conversational visual tropes, cybernetic glow effects, or decorative gradients.
- **Operational Clarity:** High-contrast text, clear boundary rules, and deterministic layout grids establish zero ambiguity around transactions, cash-flow insights, and AI recommendations.

### Visual Style
- **Minimalist Modern Merchant Tech:** Crisp, layered neutral canvases with subtle borders and targeted micro-elevation.
- **Color Discipline:** Restrained monochrome architecture punctuated precisely with iconic deep navy anchor tones, electric cyan verification signals, and standard financial status signals.

## Colors

The color palette centers on a disciplined white-and-slate substrate illuminated by selective, purposeful financial blues. Saturated accents are deployed only to denote agent interaction states, active processing, or primary operational triggers.

### Roles & Palettes

#### Primaries & Accents
- **Primary Navy (`#002970`):** The institutional core. Used for primary CTA containers, brand marks, and high-impact merchant credentials.
- **Secondary Cyan (`#00BAF2`):** The signature AI active pulse, verified agent actions, and live telemetric indicators. Used sparingly to signify live status and real-time processing.
- **Action Blue (`#0052FF`):** Interactive hyper-links, active focus rings, and secondary interactive states.

#### Neutrals & Canvas
- **Base Canvas (`#F8FAFC`):** Low-strain, neutral slate-tinted canvas background.
- **Surface Elevation (`#FFFFFF`):** Work surfaces, analytical metric cards, modals, and input fields.
- **Border Default (`#E2E8F0`):** Crisp, single-pixel structural boundaries for cards, data tables, and separators.
- **Border Subtle (`#F1F5F9`):** Internal cell divisions, sub-item dividers, and tertiary grouping lines.

#### Typography Colors
- **Obsidian / Primary (`#0F172A`):** Numbers, titles, primary text values, and critical telemetry.
- **Slate Deep / Secondary (`#334155`):** Table rows, body copy, and secondary descriptive text.
- **Slate Muted (`#64748B`):** Form labels, table headers, metadata timestamps, and inactive iconography.

#### Semantic Status Tokens
- **Success / Positive (`#059669` / Surface `#ECFDF5` / Border `#A7F3D0`):** Settled transactions, revenue growth, healthy balance indicators.
- **Agent Active (`#0284C7` / Surface `#F0F9FF` / Border `#BAE6FD`):** Autonomous agent executing, analyzing, or recommending.
- **Queued / Neutral (`#475569` / Surface `#F1F5F9` / Border `#CBD5E1`):** Scheduled tasks, pending validations.
- **Warning / Action Needed (`#D97706` / Surface `#FFFBEB` / Border `#FDE68A`):** Low liquidity threshold, pending KYC, verification alerts.
- **Critical / Error (`#DC2626` / Surface `#FEF2F2` / Border `#FECACA`):** Failed transactions, settlement drop-offs, security triggers.

## Typography

Inter serves as the singular typographic foundation across headline, body, and tabular data displays. The tracking and vertical rhythm emphasize tight, structured readability common in enterprise accounting and developer tools.

### Rules of Usage
- **Tabular Numerics:** All monetary values, transaction IDs, status counters, and percentage changes must utilize `font-feature-settings: "tnum" 1, "cv05" 1`. This prevents baseline drift and misalignments across dense financial comparisons.
- **Metric Styles:** Use `metric-lg` and `metric-md` exclusively for core financial numbers (e.g., Gross Volume, Daily Settlement, Projected Revenue). Always pair metrics with a `label-sm` category descriptor.
- **Labels & Microcopy:** `label-sm` utilizes uppercase tracking (`0.04em`) to establish crisp section dividing labels, status badges, and table header rows without relying on heavy weights.

## Layout & Spacing

The layout model enforces clean geometric logic through a strict 8-point spatial cadence (with 4px sub-steps for micro-components like badges and table cells).

### Grid Infrastructure
- **Desktop (1200px+):** 12-column responsive fluid grid within a 1440px maximum container. Margins: `2rem` (32px). Gutters: `1.5rem` (24px).
- **Tablet (768px - 1199px):** 8-column layout. Margins: `1.5rem` (24px). Gutters: `1rem` (16px).
- **Mobile (< 768px):** 4-column layout. Margins: `1rem` (16px). Gutters: `0.75rem` (12px). Side-by-side metrics wrap cleanly into vertical stacks.

### Density and Nesting Principles
- **Macro Spacing:** Canvas sections, operational workflows, and major analytics panels are separated by `space-xl` (32px).
- **Component Interiors:** Metric cards, interactive agent cards, and lists utilize `space-lg` (24px) or `space-md` (16px) internal padding to preserve an uncluttered, premium feel.
- **Micro Spacing:** Spacing between labels and inputs, icon-to-text distances, and horizontal badge gaps use `space-xs` (4px) or `space-sm` (8px).

## Elevation & Depth

Depth is established primarily through structural borders and flat surface layering, supported by subtle, cool-tinted diffused drop shadows. Heavy dramatic drop shadows, glass blurs, and neon glows are strictly avoided to maintain enterprise banking clarity.

### Depth Hierarchy

#### Layer 0: Ground Canvas
- Surface: `#F8FAFC`
- Elevation: Flat, borderless base.

#### Layer 1: Operational Cards & Modules
- Surface: `#FFFFFF`
- Border: `1px solid #E2E8F0`
- Shadow: `0 1px 2px 0 rgba(15, 23, 42, 0.04)`
- Role: Default container for KPI metrics, data tables, and agent observation panels.

#### Layer 2: Interactive Card Hover & Floating Controls
- Surface: `#FFFFFF`
- Border: `1px solid #CBD5E1`
- Shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.06), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`
- Role: Hover states for selectable AI recommendations, action cards, and segmented navigation tabs.

#### Layer 3: Dropdowns, Popovers & Contextual Agents
- Surface: `#FFFFFF`
- Border: `1px solid #E2E8F0`
- Shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.03)`
- Role: Active command menus, date pickers, autocomplete suggestions, and autonomous action confirmation popups.

#### Layer 4: System Modals & Critical Sheets
- Surface: `#FFFFFF`
- Border: `1px solid #E2E8F0`
- Shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.10), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`
- Backdrop: `rgba(15, 23, 42, 0.4)` (Deep slate veil with `backdrop-filter: blur(2px)`).
- Role: Settlement approvals, identity authorizations, and irreversible business configuration workflows.

## Shapes

The geometric framework balances human-centric software with precision tooling. Standard cards and panels use a defined radius between 12px and 16px, while inputs, interactive buttons, and granular tags employ tighter cornering.

### Geometry Architecture
- **Outer Shells & Cards (`rounded-lg` / 16px):** Core business dashboards, analytical widgets, insights banners, and modals.
- **Embedded Modules (`rounded` / 8px to 12px):** Sub-sections inside cards, table containers, notification blocks, and AI response summaries.
- **Interactive Controls (8px):** Form fields, primary buttons, dropdown triggers, and interactive list items.
- **Badges & Small Indicators (`rounded-full` / 9999px):** Status chips, agent execution pills, and numeric pill counters.
